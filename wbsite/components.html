// HARDWARE & SOFTWARE

Technical Specifications

All 7 hardware components that power the SmartRide helmet ignition system.

Arduino Nano

Helmet Controller Unit

The compact brain mounted inside the helmet. Reads FSR sensor data and controls the HC-05 Bluetooth module to send authenticated packets to the bike.

FSR-402 Sensor

Force Sensitive Resistor

Detects physical pressure inside the helmet padding. When ADC reading exceeds threshold 300, the system activates and begins transmitting WORN packets.

HC-05 Bluetooth

Wireless Communication Module

Two HC-05 modules — one in MASTER mode (helmet) and one in SLAVE mode (bike). Establishes a reliable, low-latency wireless link for packet transmission.

LED Indicators

Visual Feedback System

Green LED (Pin 5) = ignition unlocked. Red LED (Pin 6) = ignition locked. Status LED on helmet (Pin 13) = BT transmission active.

Buzzer

Audio Alert System

Connected to Pin 9 on the bike unit. Emits an alert if the rider attempts to start the bike without the helmet or removes it while riding.

5V Relay Module

Ignition Control

Connected to Pin 7. When WORN signal is received and token validated, relay closes (NO contact) completing the ignition circuit. Opens on OFFHEAD or timeout.

Battery Supply

Power Management

Rechargeable Li-ion battery for the helmet unit. Bike unit powered from the vehicle's 5V regulated supply via USB or voltage regulator.

// DEPLOYMENT

Installation Steps

  • 1
    Hardware Setup

    Connect all components to Arduino Nano (helmet) and relay board (bike) as per the wiring diagrams in the README.

  • 2
    Software Flash

    Upload helmet_controller.ino to Arduino Nano and bike_ecu.ino to the bike's Arduino board using Arduino IDE.

  • 3
    Bluetooth Pairing

    Configure HC-05 modules via AT commands — set one as MASTER (helmet) and one as SLAVE (bike), then pair them together.

  • 4
    Power ON

    Power ON both the helmet unit and the motorcycle onboard unit. Green LED should blink indicating ready state.

  • 5
    System Check

    Wear the helmet — green LED should go solid. Remove helmet — red LED activates and buzzer sounds. Test relay click.
