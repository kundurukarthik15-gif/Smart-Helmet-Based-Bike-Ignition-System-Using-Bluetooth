About The System

SmartRide is an IoT-based helmet ignition system built on Arduino Nano that enforces helmet usage by preventing the bike from starting unless the helmet is worn.

Enhancing Road Safety

The system actively improves road safety by ensuring strict helmet usage. It creates an undeniable link between the rider's safety gear and the vehicle's ignition.

Smart Processing

Powered by Arduino Nano microcontrollers, the system processes FSR sensor data in real-time, making split-second decisions without impacting the rider's experience.

Wireless Communication

Utilizes reliable HC-05 Bluetooth technology to maintain a secure, wireless connection between the helmet unit and the bike's onboard computer.

Project Overview

SmartRide is a final-year DTI project that addresses one of India's biggest road safety challenges — helmet non-compliance. Using an FSR-402 pressure sensor embedded in the helmet and HC-05 Bluetooth modules for communication, the system physically prevents the bike's ignition from activating unless the helmet is properly worn.

Hardware Stack

  • Arduino Nano — Helmet controller
  • FSR-402 — Pressure detection
  • HC-05 (Master) — Helmet BT transmitter
  • HC-05 (Slave) — Bike BT receiver
  • 5V Relay Module — Ignition control
  • LEDs + Buzzer — Status feedback

Security

Every Bluetooth packet contains an authentication token SR_UNLOCK_2024. The bike ECU validates this token before acting on any command. A 3-second watchdog timer automatically locks the ignition if the signal is lost.
